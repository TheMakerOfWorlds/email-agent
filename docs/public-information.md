# Email Agent

Email Agent is a personal, open-source-licensed desktop Gmail client and Codex plugin maintained by [Jackson Stone / TheMakerOfWorlds](https://github.com/TheMakerOfWorlds).

It lets its owner use explicitly connected Gmail accounts through compact search, read, send, organization, attachment-download, filter, Trash, and restore commands. Each account has a locally stored purpose note to help select the intended sender. This application is intended for personal use by its owner, not as a hosted email service.

## Privacy policy

Effective September 16, 2026.

**Gmail access requested.** Email Agent requests Gmail access (`gmail.modify`) for reading, sending, organizing, downloading attachments, moving messages to Trash, and restoring messages. It also requests Gmail basic settings access (`gmail.settings.basic`) to manage saved filters and support future Gmail settings features. This scope does not permit immediate permanent message deletion. Older read/send-only connections remain usable until upgraded. The Gmail connection does not request Google Drive, Calendar, Contacts, or Google account administration. Gmail read permission includes message content and the information Google exposes under that scope.

**Optional Workspace access.** A separate desktop client can connect Calendar, Meet, Drive, Docs, Sheets, and Contacts when the owner explicitly enables them. Gmail-only connections do not receive these permissions. Workspace uses verified email identity plus the selected service scopes documented in the [Workspace setup guide](https://github.com/TheMakerOfWorlds/email-agent/blob/main/docs/workspace-setup.md). Capabilities include requested calendar scheduling and guest notifications, Meet creation and accessible meeting artifacts, file/document/spreadsheet reads and edits, and saved-contact management. Drive access covers accessible existing files; the current commands do not expose file sharing, ownership transfer, or permanent deletion. Google account administration is not requested.

**Use of data.** The application searches and reads mail in response to the owner's requests, sends the messages the owner authorizes, organizes selected mail and downloads chosen attachments, moves or restores mail for requested cleanup, and manages saved filters when authorized by the owner. Optional Workspace operations likewise act on the explicitly selected account and resources in response to the owner's requests. Existing collaborators can see requested document/file edits, and authorized calendar invitations notify their recipients. Saved rules apply to future matching mail until removed. It verifies the selected account's identity and returns compact results. It does not operate advertising, resale, data-broker, or independent model-training functions.

**Local storage.** The desktop OAuth client and renewable credentials are stored in macOS Keychain. Account addresses and purpose notes are stored in an owner-only local configuration file. A local send ledger stores request hashes and compact outcomes to reduce duplicate sends; it does not store message bodies. A separate operation ledger stores request hashes and compact label/filter creation outcomes. Removed filter definitions are backed up in an owner-only local directory. Draft files and downloaded attachments selected by the owner may remain on their device.

Workspace credentials use separate Keychain records. A separate local Workspace operation ledger stores request hashes and compact outcomes/resource metadata; local uploads/downloads remain at owner-selected paths. Optional credential transfer to another owner-controlled Mac uses verified SSH and remote Keychain. Normal code updates do not copy credentials.

**Processing and sharing.** The client communicates directly with Google's OAuth, Gmail, and authorized Workspace APIs. Sending delivers the authorized message to its specified recipients through Gmail. Email, document content, contact data, calendar details, and meeting artifacts returned to Codex are also processed by the owner's configured Codex/AI service under that service's account settings and terms. Email Agent does not operate its own remote data relay or analytics server. Private content is not included in this public documentation or its GitHub repository.

**Retention and control.** Mail remains in Gmail under the owner's Google account controls. Cleanup moves mail to Gmail Trash, where it can be restored until Google automatically deletes it after 30 days. The application does not implement permanent deletion or emptying Trash. The owner can revoke Email Agent access through their Google Account's third-party connections settings. They can remove this application's Keychain records, local account configuration, drafts, downloaded attachments, filter backups, and local operation/send ledgers from their device. Removing the plugin alone does not delete those separately stored credentials and settings. Data processed by Codex/AI services is governed by those services' retention controls.

**Google user data.** Email Agent's use and transfer of information received from Google APIs will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Contact and changes.** The application maintainer is [TheMakerOfWorlds on GitHub](https://github.com/TheMakerOfWorlds). The current support email is shown on the application's Google consent screen. Updates to this notice will be reflected in its effective date.
